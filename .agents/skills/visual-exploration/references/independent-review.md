# Independent visual review

Use this gate for any software product or website. It judges the generated artifacts, not the generator's intentions.
Read it before composition so diversity and legibility are designed in rather than added at the end.
The reviewer decides whether the set is ready for the person's consideration, not which direction the person must choose.

## Build genuinely different directions

Keep the brief, task coverage, sample facts, and four specimen categories comparable across directions.
The neutral viewer can be shared. The content compositions must not be one reusable page template with different theme tokens.
Before rendering, give each direction a distinct approach to composition, typographic hierarchy, spatial rhythm, and graphic or material language.
Ground that approach in specific qualities from inspected references. A named reference world without visible evidence is not a design idea.
Let reference qualities change the work: grouping, scale relationships, reading rhythm, navigation treatment, functional marks, image treatment where relevant, or other purposeful details.
Do not invent extra features or change sample facts to manufacture variety.
Do not treat creativity as more decoration, more colours, louder type, or less usable controls.

Compare each pair using corresponding specimens before committing to all files.
If the pair still shares the same silhouette, panel structure, headline construction, and content emphasis, redesign the weaker approach rather than recolouring it.
Differences should remain apparent when direction names and explanatory claims are ignored; colour alone cannot carry the distinction.
There is no required set of moods or aesthetic categories. Choose the four from this brief, not a recurring preset menu.
Develop all four to comparable depth. Do not add a deliberately weak outlier to flatter a favourite.

## Dispatch a reviewer without process context

After the generator's own checks, use a separate reviewer with fresh context and no inherited conversation history.
This skill explicitly calls for that independent review when agent delegation is available.
Give the reviewer only the product brief, user constraints, artifact location, viewing instructions, and the criteria below.
Do not supply generation prompts, source-reference packets, the creator's rationale, preferred direction, self-assessment, prior user criticism, or a desired verdict.
Ask the reviewer to act as a senior product designer and art director, not as a compliance-only checker.
Keep the first assessment visual. Source inspection may explain a defect after it is observed, but cannot substitute for viewing the result.
Do not ask the reviewer to edit files. Its output is an evidenced critique for the generator to act on.

## Inspect the actual deliverable

Open the served viewer and render every file in every direction. Actually view the screenshots; creating captures or reading HTML alone is not visual inspection.
Judge the normal presentation scale, then inspect actual size where fit-to-stage scaling makes an issue ambiguous.
Inspect long text, ordinary labels, palettes, icons, actions, selected states, warnings, and contextual examples, not just the title sheet.
Check the viewer does not conceal clipped content or unavailable specimens. Record anything that cannot be inspected.
Check sidebar thumbnails show the actual specimens at the right proportions, remain recognisable, and expose a clear selected state rather than falling back to a text list.
For HTML, check the fonts and assets as rendered rather than assuming the declared fonts loaded.
For image specimens, inspect lettering, symbols, repeated details, edges, and material treatment for generation artifacts.
For early generated moodboards, distinguish an incidental lettering artifact from a defect that changes a task, state, action, or design decision.
Report incidental lettering as a caveat for the later HTML reconstruction; do not require repeated image generation when the intended label and visual evidence remain clear.
Do not claim contrast measurements, responsive coverage, keyboard behaviour, or working interactions unless actually checked.
A pictured focus ring is not proof of keyboard accessibility, and a static interaction sequence is not a working flow.

## Judge three separate dimensions

### Legibility and task clarity

Check text against its actual local surface, including every coloured swatch and control state. A global foreground colour is not sufficient across light and dark fills.
Check letter spacing, word separation, line length, wrapping, hierarchy, alignment, clipping, and readability at the presented scale.
Check that expressive display type does not compromise sustained reading or ordinary task labels.
Check that actions are discoverable, status words and symbols remain visible, and selected and warning states do not rely on colour alone.
Check that example counts, owners, progress, prerequisites, and outcomes agree and have clear scope.
Separate a real task contradiction from a static illustration that is correctly labelled as such.

### Creativity and diversity

Compare corresponding files across all directions. Identify the closest pair and explain what visibly separates them, or why they duplicate each other.
Judge the actual composition, typographic relationships, iconography, imagery, graphic treatment, surfaces, depth, effects, and interaction presentation, not the names or descriptions.
Require visible evidence beyond palette and type: a developed graphic and surface language carried into real task examples, not only isolated decorative samples.
Judge imagery by its relevance, quality, crop, treatment, and integration. Flag filler images and unavailable assets; do not require imagery where it would only distract from the task.
Flag a technically legible but visually underdeveloped set when ordinary boxes and labels stand in for the promised design exploration.
Do not require every effect or equate flat styling with failure; an intentionally flat direction can succeed through distinctive graphics, icons, hierarchy, and composition.
Identify the specific design move that gives each direction character and why it suits the brief. If none is visible, say so.
Flag repeated templates, generic aesthetic shorthand, arbitrary motifs, and claims of reference richness unsupported by the specimens.
Do not reward novelty that weakens the product's purpose or penalise a quiet direction merely for being restrained.

### Visual craft and art direction

Judge balance, rhythm, scale, whitespace, optical alignment, typographic pairings, surface treatment, icon coherence, and deliberate use of imagery.
Check that the four files within a direction belong to one visual system while serving their different purposes.
Distinguish purposeful restraint from empty filler and expressive contrast from accidental inconsistency.
Identify what should be preserved, not only what should change.

## Report and gate

Return READY, REVISE, or BLOCKED for the set, plus a verdict for every direction.
READY means every file was visually inspected, no presentation blocker remains, and the directions provide meaningfully different, adequately crafted choices.
REVISE means observable defects or insufficient diversity prevent presentation as a finished exploration.
BLOCKED means missing files, broken rendering, or unavailable inspection prevents an honest verdict.
Do not average away a serious legibility failure because another specimen looks good.
Treat unreadable important text, disappearing controls or warnings, clipped content, misleading task states, and materially duplicated directions as presentation blockers.
Distinguish observed defects from design judgments; explain both with visible evidence rather than presenting taste as objective fact.
For each finding, name the file and element, the observed issue, its effect, and a concrete correction that preserves useful qualities.
List files actually inspected, inspection limits, the closest pair, and qualities worth keeping. Do not invent an issue quota or unsupported numeric scores.

Have the generator resolve blockers in the source artifacts, then return the changed files to the reviewer for confirmation.
When compositions change, compare the four directions again rather than reviewing the replacement in isolation.
Present only the reviewed revision as ready; include any remaining non-blocking caveats briefly.
If independent review is unavailable, disclose that limit and offer an explicitly unreviewed preview rather than silently substituting self-review.
If blockers remain after two correction rounds, stop and report them with the draft instead of looping indefinitely or claiming success.
The person can request a draft at any point; label its review status honestly and never imply approval on their behalf.
