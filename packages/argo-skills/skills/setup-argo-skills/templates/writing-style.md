## Writing style

**Anything a person reads and answers, or reads after you are gone, goes through the
`simple-english` skill first.** An issue title and body, a comment, a close message, a PR title
and body, and every question you put to the user, a grilling round included. It runs on the
draft, not as a cleanup pass afterwards.

**Anything an agent reads goes through the `writing-for-agents` skill first**, this file
included: a skill, an `AGENTS.md` section, a doc reached by a pointer. Same rule, other audience,
and the two never merge — one is written to be understood by a person, the other to be executed
the same way every run.
