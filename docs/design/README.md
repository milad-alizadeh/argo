# Desktop design kit

The browser side of the `apps/desktop` token contract. A design page opens from `file://` and
resolves every value through `tokens.css`, so it shows the contract that is in the tree rather
than a copy of it.

| File | What it is |
| --- | --- |
| `tokens.css` | The contract mirrored for a plain browser page. Generated by `bun run design:tokens`. |
| `design-template.html` | The starting point for a screen's design page. |
| `kit.js` | Render functions for shapes a design page repeats. |

The contract itself is `apps/desktop/src/renderer/styles/globals.css`. Edit it there, then
regenerate the mirror.

A screen's approved design lives in its **design ticket** and on a `design/#<N>-<screen>` branch,
never here and never on `main`. `docs/designs/` (plural) is the closed `apps/macOS` archive.
