# Design stack

- **Token contract** — `apps/desktop/src/renderer/tokens.css`, the only source of design constants.
- **Browser mirror** — `docs/designs/tokens.css`, generated by `bun run design-tokens:sync`.
- **Components live in** — `apps/desktop/src/renderer/`, and each design state is isolated through Storybook stories.
- **Isolated-state mechanism** — Storybook states in `apps/desktop/src/renderer/*.stories.tsx`, added with one prop set per state.
- **Render a state** — `cd apps/desktop && bun run design:render`, output `docs/designs/renders/app-surface.png`.
