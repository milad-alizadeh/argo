    Where this standsone variation, refined in place

    • The filename is the whole address. No path in the feed; siblings take a one-word parent qualifier (· Specimen) and the full path is the panel's breadcrumb.
    • A call is a sentence, not a row. Icon, verb, name, diffstat. No fixed columns, no right-hand meta rail, no timestamp — columns are what turned #378 into a log table.
    • The plan is not a feed event. It is standing state, so it floats as a pill above the dock and opens on hover.
    • Disclosure only where there is something behind it. The "Edited files" group has a caret because it collapses; a single line has none; media with no bytes is inert (D36).
    • Contract gaps, still open: diff inks (borrowing state.running / state.failure, which collide with a running dot), syntax inks for the panel, and a feedRow metric group.
    • Undecided: panel as a 54% split (as here) or an overlay; whether opening a file takes width from the feed or the Agents rail. Overlaps #380.
