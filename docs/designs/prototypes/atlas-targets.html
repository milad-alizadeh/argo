What Argo is made of

A macOS window that starts coding agents, watches them work, and talks back to them.

Three parts, listed top to bottom. Each one may use what is below it, never what is above.

The app target

943 lines

Nine files that open one window and hold the three boxes everything else hangs from.

ArgoUI

52,804 lines · 5 groups

Every screen the window draws. It is handed values to draw, and one file only is allowed to read live state.

Open its five groups →

ArgoEngine

20,622 lines · 4 groups

The part with no window. It reads what agents write, drives the agents it started, and talks to GitHub and Linear.

Beside the stack, not in it

ArgoTerminal

140 lines

Two files that own a real terminal. They sit apart because the terminal library needs the UI framework, which ArgoEngine may not use.

argo-observe

131 lines

A command you run in a terminal. It points the engine at one transcript and prints what each record means.
