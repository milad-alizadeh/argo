# How many hand-picked text rungs the tree stands at (#1250). One number, and it may only fall.
#
# A call site that names a rung — `argo.color.text.tertiary` — has made the kind/rung pairing
# again by hand, which is what `ArgoLineKind` and `TextRoles.ink(_:)` exist to stop. It cannot be
# banned outright: a glyph, a stroke, a dot and a ghosting comparison all take a rung legitimately
# and none of them is a line of text. So it is a budget.
#
# Converting a call site to its kind lowers the count, and the gate then fails until this number
# is lowered with it: a budget left above the tree authorises the next call site written to the
# shape that was just removed, which is how a ratchet stops.
#
# This number was raised ONCE, from 247 to 253 (#1511). 247 was written six below the tree it
# landed on, so it described no tree and refused every Swift commit in every worktree; 253 is the
# count the script reports. That is the one exception and not a precedent: the ratchet still only
# falls, and a raise is a correction only where the old number never described a tree at all.
#
# `scripts/ratchet-thresholds.test.mjs` holds it to the tree from the Linux CI job.
251
