# Reasons for the DUPLICATION gate's ignore list (`.jscpd.json`).
#
# They live in a sidecar file because `.jscpd.json` is plain JSON and a comment in
# it makes jscpd's auto-discovery skip the whole config silently — no threshold, a
# different file count. So the config stays comment-free and its reasons live here.
# Keep the two in sync: an ignore glob with no reason below is an unexplained
# exemption. Each entry is labelled KIND (the rule does not apply to that category)
# or RATCHET (debt; the list may only shrink), the same convention as biome.jsonc.
#
# `quality:duplication` passes `--config .jscpd.json` explicitly, which parses
# rather than discovers and hard-errors on a malformed file — that is what closes
# the fail-open. Keep the flag. And do not re-prove a config change by exit code:
# `jscpd … -t 0` exits 1 whether the config loaded or not. Check the analysed file
# count, or plant a clone pair in an ignored path and one outside it. See AGENTS.md.

  **/node_modules/**, **/dist/**, **/out/**, **/graphify-out/**
    KIND: not our source. Vendored and generated output.
  **/*.stories.tsx
    KIND: declarative story catalogs — the duplication between stories IS the
    coverage. The line ceiling waives them for the same reason (biome.jsonc).
  prototypes/**
    KIND: throwaway research prototypes; copy-paste is the fastest way to
    compare two variants, which is the point of a prototype.
  **/skills/**/templates/**
    KIND: a skill payload template and the copy it installs are the same file
    by design. Deduplicating them would break the payload.
