# Asset-first exploration

Read [the common brief](../common.md).

Before laying out the studies, develop four distinct sets of visual ingredients around the user's subject. For each, make a substantive original graphic or illustration, select a real icon family, and establish a surface treatment. Use image generation when it will produce richer original material than markup alone; precision vectors and sourced assets can serve other roles. Let the assets have different visual logic, not just different colours.

Compose the mood studies from these ingredients with real typography and colour samples. Then make the UI fragments show the same visual language in use, choosing useful layout and controls for the user's work. Keep imagery out of reading areas when it would impair use.

This variant tests whether making concrete ingredients before page layout prevents empty, text-heavy moodboards.
