# Image-led exploration

Read [the common brief](../common.md).

Use the available image-generation tool to explore four distinct visual compositions for the user's brief before writing the study layouts. Ask for visually rich art direction with imagery, illustration, materials, graphic detail, and interface-shaped composition. Treat generated words and controls as provisional visual suggestions, not final usable UI. If image generation is unavailable, report that this experiment cannot be tested as specified rather than silently substituting CSS rectangles.

Translate the compositions into HTML studies, preserving their interesting spatial relationships and visual assets while replacing all UI text and controls with precise HTML and coherent real icons. Generate clean separate assets where the initial image cannot be used without embedded text or interface artifacts. Do not flatten an entire generated board into the final HTML and call its text usable.

Let the mood study carry the strongest visual composition; let its UI examples demonstrate that the direction survives realistic work. This variant tests image generation as the art-direction medium and HTML as the precision and presentation layer.
