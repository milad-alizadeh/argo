# Reference-led exploration

Read [the common brief](../common.md).

Research and visually inspect relevant work from reputable design studios, designers, museums, or original product sources. Gather different kinds of inspiration rather than four examples of one interface genre. Extract specific principles from their composition, imagery, typography, material, or graphics, not a list of style adjectives.

Develop four original directions by combining those principles in new ways for the user's task. References are ingredients, not page templates: do not copy one source's layout, branding, and palette wholesale. Use available image generation, illustration, and coherent icon assets to realize the new directions. Include source links in a separate credits record so the mood study remains visual rather than a research essay.

Build each mood study and its UI examples as one visual language, with task-appropriate controls and comfortable reading. This variant tests whether concrete visual references improve the specificity and richness of original assets and compositions.
