# Visual exploration

Interview the user before designing. Establish the audience, product purpose, key tasks, realistic content, devices, desired feeling, existing brand constraints and accessibility needs. Wait for their answers.

Use `/Users/milad/Developer/argo/.agents/skills/frontend-design/SKILL.md` to design and build from that brief.

Deliver four distinct directions. Each includes one rich visual mood study showing typography, palette, graphics, icons, imagery where useful, surfaces and UI fragments. Follow it with three fully designed product screens: a populated working view, a form in progress with validation, and a different core workflow. Carry the study's actual visual assets into these screens: useful icons in controls and navigation, a substantive illustration or subject image where relevant, and a distinctive background or surface treatment. Show assets doing a job beside realistic content, not isolated decoration. Layouts may differ completely between directions and examples.

Present the sixteen artifacts in the adjacent `viewer.html`, grouped by direction, with the mood study first and actual artifact thumbnails. Keep scene content compatible with its script-free iframes. Serve the preview locally and report its URL and output directory.
