# Visual exploration

Interview the user before designing. Establish the audience, product purpose, key tasks, realistic content, devices, desired feeling, existing brand constraints and accessibility needs. Wait for their answers.

Use `/Users/milad/Developer/argo/.agents/skills/frontend-design/SKILL.md` to design and build from that brief.

Deliver four distinct directions. Each includes one rich visual mood study showing typography, palette, graphics, icons, imagery where useful, surfaces and UI fragments. Follow it with a populated product screen, a second screen for a different core task, and a composed UI specimen sheet showing a filled form with validation, navigation, buttons, selection controls, search/results, feedback and a coherent icon family. Use realistic product content and designed states rather than labels describing components. Layouts may differ completely between directions and examples.

Present the sixteen artifacts in the adjacent `viewer.html`, grouped by direction, with the mood study first and actual artifact thumbnails. Keep scene content compatible with its script-free iframes. Serve the preview locally and report its URL and output directory.
