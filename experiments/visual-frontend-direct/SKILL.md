# Visual exploration

Interview the user before designing. Establish the audience, product purpose, key tasks, realistic content, devices, desired feeling, existing brand constraints and accessibility needs. Wait for their answers.

Use `/Users/milad/Developer/argo/.agents/skills/frontend-design/SKILL.md` to design and build from that brief.

Deliver four distinctly different visual worlds, not four reskins: give each its own mood, colour relationships, typography, composition and graphic character. Each includes one rich visual mood study showing typography, palette, graphics, a coherent icon family, backgrounds, surfaces, imagery where applicable and UI fragments, followed by three substantial UI examples showing different tasks or states within that direction. Show these visual assets in use throughout the UI examples, not just as isolated samples in the study. Within each direction, vary the examples' composition, density and asset use to suit their different tasks while retaining a recognisable identity. Layouts may differ completely between directions and examples; richness should not come at the expense of readable content.

Present the sixteen artifacts in the adjacent `viewer.html`, grouped by direction, with the mood study first and actual artifact thumbnails. Keep scene content compatible with its script-free iframes. Serve the preview locally and report its URL and output directory.
